# Controle Financeiro

Aplicação web desenvolvida com React para gerenciamento de receitas e despesas.

## Projeto online

Acesse a aplicação publicada no Vercel:

https://controle-financeiro-gilt-one.vercel.app/

## Funcionalidades

- Cadastro de receitas e despesas
- Edição de transações
- Exclusão com confirmação
- Filtro por receitas e despesas
- Filtro por mês
- Busca por descrição
- Ordenação por data e valor
- Saldo atual
- Total de receitas
- Total de despesas
- Gráfico de receitas x despesas
- Gráfico de despesas por categoria
- Persistência dos dados com LocalStorage
- Layout responsivo

## Tecnologias

- React
- JavaScript
- Vite
- Recharts
- CSS
- LocalStorage
